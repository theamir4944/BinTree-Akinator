# 1. Введение в BinTreeGraph (Akinator)

В данном проекте на основе бинарного дерева была реализована пародия на игру "Акинатор"

Акинатор — это игра, где джинн Акинатор пытается угадать персонажа, которого ты загадал, задавая серию вопросов.

Игрок мысленно выбирает персонажа

Акинатор задаёт вопросы с вариантами ответов: «Да», «Нет».(В отличие от оригинала варианты ответов «Возможно частично», «Скорее нет», «Я не знаю» недоступны, так как это значительно усложняет реализацию задачи)

Каждый ответ сужает круг кандидатов — система опирается на статистику ответов других игроков.

Если персонажа нет в базе, его можно добавить — так игра «учится».


# 2. Возможности

## tree_funcs.cpp - файл с набором основных функций для взаимодействия с бинарным деревом

bt_create_node - создать новый узел

bt_destroy_node - удалить узел

bt_link_node - "подвязать" узел

bt_form_header - формирование хедера для дамп-файла (вспомогательная функция)

recursion_dump - рекурсивное добавление узла в дамп-файл (вспомогательная функция)

bt_dot_dump - формирование dot-дамп-файла с возможностью "подсветки" узла (вспомогательная функция)

bt_graphviz_dump - конвертация dot-файла в изображение (вспомогательная функция)

paste_pngs - вставка изображения в htm-файл (вспомогательная функция)

bt_make_html - формирование htm-дамп-файла

bt_goto_child - перемещение к ребенку узла

bt_goto_parent - перемещение к родителю узла

## numbertreelib.cpp - файл с набором функций для чтения/записи бинарных деревьев с нестроковым типом данных

read_tree - чтение дерева

preord_rec_reading - рекурсивное чтение дерева из файла, записанного в форме preorder (вспомогательная функция)

inord_rec_reading - рекурсивное чтение дерева, записанного в форме inorder (вспомогательная функция)

postord_rec_reading - рекурсивное чтение дерева, записанного в форме postorder (вспомогательная функция)

write_tree - рекурсивная запись дерева в файл

preord_rec_writing - рекурсивная запись дерева в форме preorder (вспомогательная функция)

inord_rec_writing - рекурсивная запись дерева в форме inorder (вспомогательная функция)

postord_rec_writing - рекурсивная запись дерева в форме postorder (вспомогательная функция)

## treelib.cpp - файл с набором функций для чтения/записи бинарных деревьев со строковым типом данных

read_text_value - прочтение нового текстового значения из файла

preord_text_reading - формирование дерева на основе данных в файле, записанных в форме preorder (Для строковых деревьев реализована только форма preorder, остальные опущены ввиду ненадобности в рамках этой задачи)

read_text_tree - обертка для preord_text_reading

preord_text_writing - рекурсивная запись дерева в форме preorder

write_text_tree - обертка для preord_text_writing

seek_node - нахождение узла по его значению (потребуется для определения и сравнения в Акинаторе)

get_def_tostack - запись обратного определения в стек (вспомогательная функция)

## outer_wrapper.cpp - графическая обертка для функций Акинатора - Файл сделан с целью уйти от взаимодействия с терминалом (Понятно, что "идейно" всё заработает и в терминале, но, очевидно, обычному пользователю приятнее взаимодействовать с чем-то визуально понятным, чем с терминалом)

raylib_enter_text - ввод текстового значения в окне

raylib_button_bool_ans - кнопочный выбор ответа (Да/Нет)

raylib_show_text - вывод текста на экран

## akinator_main.cpp - непосредственно Акинатор

akinator_guessing - работа Акинатора в режиме отгадывания

get_new_node - обучение Акинатора - добавление нового элемента и его отличия в базу данных

get_full_defenition - работа Акинатора в режиме определений

get_comparison - работа Акинатора в режиме сравнения

# 3. Требования и сборка

Для запуска программы потребуется компилятор языка C/C++ (К примеру, g++/clang++)

Также понадобится сторонняя программа для построения графов - Graphviz (все инструкции для установки можно найти на [сайте Graphviz](https://www.graphviz.org/))

Также потребуется библиотека raylib - подробнее о установке можно прочитать в [одном из предыдущих проектов](https://github.com/theamir4944/Virtual_processor)


Файлы akinator_main.cpp ; tree_funcs.cpp ; treelib.cpp ; outer_wrapper.cpp следует расположить в одной папке + в этой же папке следует создать папку dump_pictures (чтобы туда сохранялись изображения, далее используемые в htm-дампе)

Далее следует скомпилировать файл с Акинатором командой 
``` bash
g++ .\akinator_main.cpp -o .\akinator_main.exe -lraylib -lopengl32 -lgdi32 -lwinmm -lm
```
(Очевидно, с нужными флагами для работы raylib)


Запуск Акинатора производится командой 
``` bash
.\akinator_main.exe      
```
